# 1.3 浏览器验收记录

2026-10-21，Cua 浏览器操作，本地 Java/JDBC 1.3.0-rc1。对应 JAR SHA256：`3191b4c6ac4d451217c58b6f4cfcbc0c8c2dd1d5d8f9cfe1b4dadb494ecce3fc`。

- 七类现有账号分别密码登录，核对默认首页、菜单和权限范围；桌面 1440 px 均无整页横向溢出。诊所经理拥有获授权的临床查看菜单，不把“可查看”误判为“可签署”。患者仅有本人入口与账号安全。
- 预约工作区检查日期导航、空日程、看板、关键词检索、牙椅分组及未分配记录，日程卡片能够打开持久化预约和状态历史。
- 手机 390 px 检查患者入口、前台日程与公开首页；表格、时间表在各自组件内滚动，整页没有横向溢出。
- 保留鼠标／焦点在轮播控件后，实际观察场景自动变化；手动暂停保持，点击播放恢复。最终重新进入首页，默认自动播放，不遗留暂停状态。
- 检查功能页签、32 牙位示意及 End 键切换。所有公开示意均标明为合成场景，不能视作患者数据或直接操作入口。
- 自动化有一次快速填充返回 LOGIN_FAILED；稳定表单重新填入原凭据后成功。只读核对七组凭据与数据库散列匹配，未重设密码；不对该次自动化失败作未经证实的归因。

机器可读观察与 13 项交互见 [JSON](browser-review-v1-3.json)。这些是只读 UI 检查，完整写入流程在隔离 SQLite / PostgreSQL HTTP 验收中进行，不修改本地既有病历、账单或预约。
