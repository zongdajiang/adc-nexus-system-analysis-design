# 1.2 浏览器复验

日期：2026-10-21。环境：本机 Java 21、SQLite、Cua 控制的应用内浏览器。使用已有七类私人合成测试账号，未重设密码，未通过页面创建诊疗或资金记录。

机器可读记录见 `browser-review-v1-2.json`。它与集成测试分别记录：浏览器确认真实页面与交互；后端脚本在独立数据库中执行业务写入、并发、越权及恢复验证。不能相互替代。

| 范围 | 实测结果 |
|---|---|
| 七类账号 | 前台→预约，医师→临床，收费→结算，经理/总部运营→工作台，总部财务→期间核算，患者→本人入口；菜单按实际授权区分 |
| 首页轮播 | 暂停、上一/下一场景与指定分页；三段文案和场景对应；图片实际加载 |
| 功能预览 | 临床预览包含 32 个 FDI 恒牙标识；方向键切到经营说明；示意界面不作实时数据 |
| 业务与权限说明 | 季度复核与单次就诊分开，患者本人权限和发送通道缺配置均明确说明 |
| 功能查找 | 医师搜索“结算”不列出未授权入口；经理搜索“预约”可用 Enter 跳转实际页面 |
| 手机菜单 | 390×844 视口，抽屉展开、Esc 关闭、焦点返回触发按钮；关闭后菜单有 inert 保护 |
| 手机表格/表单 | 宽表仅在表格容器内滚动，有提示；预约弹窗在视口内，内部滚动且操作栏可见，随后取消而不保存 |
| 响应式 | 390×844、900×1100、1440×1000 视口复查，无整页横向溢出；不等于物理手机设备验收 |
| 中英切换 | 工作区标题和导航切换后可恢复中文；首页为中文产品说明 |
