# 首页比例与响应式修订

日期：2026-10-22。适用：本地 `1.4.0-rc1` 的 `homepage-layout1` 样式补丁。

## 问题与处理

原布局把文字固定在 1240 px 的居中版心内，图片却按视口百分比绝对定位并延伸至右边缘。2560 px 测试视口下，文字左边距约 652 px，左右边界不一致。

本次将首屏文字、场景图片和轮播控件放入同一 CSS Grid，统一导航、首屏和正文版心。版心上限为 1880 px，两侧留白随屏幕缩放；相同宽屏下文字左边距约 332 px。桌面双栏约为 43∶57，中间保留独立栏距，不再用图片偏移挤压文案。

标题、正文和按钮按阅读层级适度放大；限制段落行宽，避免宽屏文字过长。首屏高度随屏宽调整，笔记本不再沿用宽屏大高度。900 px 及以下改为图文上下排列；650 px 及以下将轮播状态独立成行；额外修正 380 px 及以下导航宽度。接待、诊疗、结算入口沿同一网格排列，小屏依次换行。

## 修改边界与备份

运行产物仅 `web/practice.css`、`web/index.html` 两个条目变化，后者只调整 CSS 缓存版本。Java 类、SQL、图片、JavaScript、登录、岗位权限及业务操作均未改变；工作区与认证 CSS 保留原字节。

修改前 CSS、HTML、JAR 与 QA 文件已保存到本机被 Git 忽略的 `data/before-home-layout-20261022-bb1a8a86c95b43499fad9e44766dd57b/`。未向 GitHub 推送，未覆盖此前完整交付包。
