# ADC Nexus 1.2 · 本地精修交付

日期：2026-10-21。首页、统一登录与岗位业务工作区已经更新；这是可运行、经本地验收的发布候选版，不是已经发布的公网医疗系统。

## 先看新版

在现有电脑双击桌面 `ADC Nexus - Start`，打开 [本地首页](http://localhost:8087/)。如仍显示旧样式，按 Ctrl+F5。桌面 `Status` 检查版本和数据目录，`Stop` 停止本项目服务。已有账号及密码不变。

请继续使用原工程及其 `data/`。不要为了查看新版而重新解压、初始化或覆盖数据库。电脑关闭、休眠或服务退出后，本地链接可能不可用；重新启动服务即可。本地链接不能交给异地教师代替公开 HTTPS 链接。

## 包内内容

| 内容 | 用途 |
|---|---|
| `ADC_Nexus_JDBC_1.2.0-rc1.jar` | Java 21 可运行程序，内含页面、原创图像和 JDBC 驱动 |
| `ADC_Nexus_JDBC_1.2.0-rc1_Source.zip` | 经允许清单打包的源码、文档、图像及 QA；不含本地数据库、密码、会话、日志或构建缓存 |
| `source/` | 与源码压缩包相同的展开版本，便于审阅；不是现有业务数据目录 |
| `release-manifest.json` | 文件大小与 SHA-256，用于核对交付文件完整性 |

新电脑须安装 Java 21+。从源码重建可执行 `mvn -B -ntp package`；构建后用 `tools/local-server.ps1 -Action Start` 启动本地合成环境。这会建立该新目录自己的数据，不会自动继承原电脑的私人测试账号。迁移数据库应另外备份并受控执行，不能上传至公开 GitHub。

## 本轮完成与边界

公开首页提供轮播、分段浏览、功能演示和岗位说明；登录后的页面依照服务端授权显示不同工作区，统一了业务表格、表单、状态与手机布局。新增功能查找只搜索本人有权访问的页面，不搜索患者数据。

自动化验收：业务 SQLite 131、PostgreSQL 129；统一身份 51、49；请求与 CSV 辅助 10；首页 HTTP/源码合同 23，共 393 项。PG 恢复另核对 10 条业务链及 137 条有效外键；65 张业务表数量、已有账号凭据、数据库完整性保留。浏览器实测、截图和被测 JAR 校验值见 `source/qa/`，不等同真实发送、压力测试或医疗生产合规验收。

首页两幅照片为 imagegen 生成的虚构场景，已在页面标明；规格记录见 `source/docs/VISUAL_ASSETS_V1_2.md`。布局按 Sites 的分段叙事、可读性与交互规范处理，没有复制参考网站品牌、客户或成效数字。
