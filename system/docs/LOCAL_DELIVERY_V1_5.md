# ADC Nexus 1.5 · 本地验收与待发布包

当前版本使用 Java 21 / JDBC，不使用 JPA；本地 71 张表、820 个字段、146 条外键。原报告保持冻结，待公网发布及验收完成后同步。

## 查看与试用

桌面 `ADC Nexus - Start` 启动，浏览器访问 `http://localhost:8087/#/home`；刷新页面加载新版本。`Status` 检查运行状态，`Stop` 安全停止。现有本地账号和业务记录保留；不把本机地址称为公开系统链接。

统一登录后，岗位从实际授权决定。综合合成演示便于连续演练，但不代替真实岗位验收。真实短信/邮箱未配置时，相应验证码注册和找回明确不可用；不要输入真实患者资料或真实付款信息。

## 本轮变化

- “组织与资源”可维护诊所、医师档案、牙椅、设备及营业时间；已有预约会阻断有冲突的停用或缩时。
- 治疗目录通过追加版本改价，标明有效期和必需资质，保留历史金额。
- 预约详情单独登记患者联系确认；历史明确区分预约建立、联系确认与状态变更。
- 医师在本次就诊提出复诊建议；前台在“候补与复诊 → 复诊跟进”记录联系、关联正式预约并核实完成。

详细合同见 [1.5 增量规格](PRACTICE_UPGRADE_V1_5.md)，原业务主路径见 [教师试用指南](REVIEW_GUIDE.md)。每次更新记录在 [升级台账](../upgrade-workbench/2026-10-30/CHANGE_LEDGER.md)，最终报告同步使用 [核对索引](../upgrade-workbench/2026-10-30/REPORT_SYNC_INDEX.md)。

## 交付边界

自动化检查、真实浏览器交互、独立 PostgreSQL 恢复和原有数据保留分别留证，具体以包内 QA 及发布清单为准。Render / Neon 登录、创建免费资源、真实 HTTPS 链接、托管重启持久化与云端恢复尚需完成，不提前标为成功。

源码包不含数据库、密码、会话、日志、云端连接串、原始第三方 XML 或构建缓存。JAR 需安装 Java 21；本地启动工具留在源码 `tools/`。发布说明见 [Render + Neon](DEPLOYMENT.md)。
