# ADC Nexus 1.4 · 日常诊疗工作台

当前为本地验收版，不是已完成公网发布的生产医疗系统。Java 21 / 参数化 JDBC；不使用 JPA。现有本地数据库、账号和密码保留。

## 查看

使用桌面 `ADC Nexus - Start` 启动，打开 `http://localhost:8087/#/home`。`Status` 检查后台，`Stop` 安全停止。运行中刷新浏览器加载新版本；电脑关闭或休眠时本地链接不能保证可用。原有测试账号继续使用，不在公开压缩包内附密码。

## 变化

- 前台默认进入门诊日队列，按服务日期、医师和患者检索，核对身份后办理到诊；历史记录不冒充今天的业务。
- 医师查看未完成接诊队列，本次就诊分风险、检查、方案、实施、病历五区；患者身份及过敏提示持续显示，完成条件由服务端核验。
- 收费员直接处理待开单、待收款及单据追查；单条就诊预选开单，成功后进入对应单据。
- 重整首页、登录和所有岗位共享的字体、导航、表格、状态色与留白；真实患者检索与功能菜单搜索分开。

详见 [1.4 工作流规格与调研](PRACTICE_WORKFLOW_V1_4.md) 和 [视觉材料说明](VISUAL_ASSETS_V1_4.md)。

## 交付内容

JAR 可运行程序、`source/` 源码与增量规格、源码 ZIP 和带 SHA256 的清单。运行数据、口令、会话、日志、密钥、构建缓存不打入公开源码包。原设计报告保留，不将增量规格伪称为最终 PDF 已全量同步。

新机器先安装 Java 21，执行 `java -jar ADC_Nexus_JDBC_1.4.0-rc1.jar` 会在该工作目录创建独立演示库，**不会自动带入当前电脑的数据**。仅课程评审需要时显式设置 `DEMO_MODE=true`；正式业务应关闭公开演示入口。首次管理员凭据写入本机被忽略文件，不应上传。

## 验证与未完成范围
