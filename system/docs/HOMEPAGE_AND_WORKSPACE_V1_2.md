首页借鉴的是参考站“导航—场景—分层内容—行动入口”的信息组织方式，不复制商业数字、客户评价、收费方案或尚未实现的功能。首页的业务小界面标作“合成场景示意”，不是实时统计。

69 张实施表包含原 61 张设计表及后续业务证据、账号和技术表。七类业务角色不包含系统管理员和课程综合演示身份；二者不等同真实临床岗位。表和权限的详细差异见 [变更记录](CHANGE_CONTROL.md) 与 [SDS](SDS.md)。

## 本地访问与桌面入口

入口：[http://localhost:8087/](http://localhost:8087/)。如页面保留旧样式，请使用 Ctrl+F5 刷新。

桌面已有三个快捷方式：

- `ADC Nexus - Start`：启动已有 JAR 并打开首页；不编译、不重建数据库。
- `ADC Nexus - Status`：检查服务及版本，显示数据库目录。
- `ADC Nexus - Stop`：停止由本启动器记录并核实身份的 Java 进程；保留数据和账号。

脚本从自身目录推导项目路径，使用绝对 `DATA_DIR`、相对 ASCII JAR 参数，避免 Windows 中文路径被原生参数编码破坏。进程归属以 PID、启动时间、Java 路径和启动参数联合核对；端口不属于本项目时拒绝误停。启动失败的日志位于被 Git 忽略的 `data/logs/`。日志及账号文件不要直接公开。

启动器只绑定本机回环地址，不安装开机自启、Windows 服务或定时任务。关闭电脑、休眠、退出系统或异常终止仍可能使服务不可用，重新双击 Start 即可；这不是持续运行的公网部署。桌面源码包的 `system/` 目录不是另一套现有数据库，请勿为了启动而复制或新建患者数据。

重新安装快捷方式时，从实际运行项目目录执行 `tools/install-shortcuts.ps1`。如果已存在指向另一项目的配置，脚本会停止，避免悄悄改变数据来源。

## 保留的业务与安全边界

本轮没有新增物理表、重设既有密码、改变角色授权或生成新的业务记录。登录、登出会写会话和安全审计，这是预期行为。

- 预约仍在事务中核验任职、资质、班次、牙椅和并发冲突。
- 医师临床写入仍受本人负责关系约束；收费员不因此获得临床病史权限。
- 患者仅可访问已核实绑定的本人资料。
- 收退款仅登记合成业务凭据，不执行银行或支付平台划款。
- 期间核算、成本核实、费用归属、核定快照、10% 激励池口径未因界面美化而改变。
- 手机/邮箱真实送达尚未验收；注册不能绕过双联系方式验证及员工名册比对。

## 验收证据与回退

自动化结果保存在 `qa/`，包含业务、账号、请求重试/CSV、首页 HTTP/源码合同检查。浏览器实测与截图单独记录，不把源码检查说成浏览器验收。各项发布证据须与当前 `target/adc-nexus.jar` 的 SHA-256 核对。

修改前的源码及一致性 SQLite 备份保存在本地 `data/before-homepage-20261021/`，不会进入公开源码包。若需回退，先停止服务、另存当前数据，再由维护者按已验证备份恢复；不要把整个 `data/` 删除或覆盖。

正式交付前仍需完成：Render/Neon 的持久化公网部署、真实身份发送通道、云端备份恢复试验、外部浏览器试用，以及最终报告的架构/账号/界面/实施差异回填。原报告不会因本增量被宣称已经与软件 100% 同步。
