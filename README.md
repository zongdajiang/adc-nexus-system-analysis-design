# 安德鲁牙科连锁运营管理系统：系统分析与设计

系统分析与设计课程作业，围绕 Andrew's Dental Chain 案例建立业务、需求、分析和设计模型。主报告涵盖业务用例与现状/改进流程、系统用例与规约、分析模型，以及关系数据库设计。该仓库用于提交和审阅设计成果，不是可直接部署的业务系统。

## 报告结构

- **A 业务建模**：业务目标、业务用例、现状与改进后的业务交互。
- **B 需求**：系统用例及主要用例规约。
- **C 分析**：领域类、分析序列和状态模型。
- **D 设计**：职责与界面/部署边界、关系数据全景和九个业务域、字段目录及业务规则。

数据设计按组织授权、身份通知、患者主档、人员目录、预约资源、临床就诊、结算资金、期间核算和扩张规划九个业务域组织。当前设计快照包含 **61 张表、730 个字段、119 条已声明外键和 124 个索引**。图中标记的建议增强关系与性能候选项不计作现有约束；正式短信/微信通道和部分财务归属功能也未被写成已验收功能。

## 设计边界与资料说明

现状业务中的纸质/本地台账等细节是依据课程案例所作的分析假设，不等于对真实诊所的访谈结论。关系模型是课程设计快照，真实上线前仍须核定临床、隐私、财务及机构制度。案例全文和课程课件因版权未附入仓库；引用信息见报告末尾参考文献。
