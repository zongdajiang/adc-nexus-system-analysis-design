# ADC Nexus · 安德鲁牙科连锁运营管理系统

系统分析与设计课程项目。员工端覆盖预约接待、诊疗、收费及经营核算，患者端提供预约、就诊摘要和账单查询。课程演示使用合成数据。

## 课程验收入口

- **[系统分析与设计报告（PDF）](分析设计文档/ADC_Nexus_主文档.pdf)**。共 148 页，可[下载原版 PDF](分析设计文档/ADC_Nexus_主文档.pdf?raw=true)或[查阅图册与源文件](分析设计文档/)。
- **[员工端演示系统](https://adc-nexus-demo.duckdns.org/#/home)**。打开后点「登录」，从登录页选用六个岗位的演示账号。
- **[患者小程序体验码](#患者小程序--微信扫码体验)**。用已加入「体验成员」的微信扫码。

### 患者小程序 · 微信扫码体验

**体验码在 2026 年 12 月 2 日前有效。** 微信扫码后，点击小程序登录页的「直接体验」。在手机上查看时，可保存图片并从微信「扫一扫」的相册中选取。
