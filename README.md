### 患者小程序 · 微信扫码体验

![ADC Nexus 患者服务体验版二维码，12 月 2 日前有效](assets/patient-preview-qr.png)

**二维码于 12 月 2 日前有效。** 请使用已加入「体验成员」的微信扫码，进入登录页后点击「直接体验」。

ADC Nexus 支持患者建档、预约与资源安排、到诊接待、医师诊疗、收费退款、复诊跟进及经营核算。员工统一登录，按岗位和所属诊所进入对应工作台。服务端使用 Java 21 和 JDBC，网页随应用一起运行。本地试用使用 SQLite，服务器演示使用隔离的 PostgreSQL 和合成数据。

## 交付和验收

报告共 148 页，含 83 张编号图。系统源码和部署文件来自已核验的交付。复核记录覆盖六个业务岗位的核心流程、权限请求、PostgreSQL 初始化及备份恢复，以及员工页面的响应式浏览器检查。公网课程演示已复验 HTTPS、六岗位登录、桌面和移动端核心页面，以及数据库重启后的数据持久化。

![诊所经营工作台](qa/交付复核/桌面%201440%20宽%20诊所经营.png)

患者微信小程序在独立私有仓库维护，使用合成数据演示。当前报告的患者端章节基于原交互原型，成品实施差异另行核对。

现行报告源文件以表中压缩包为准。仓库较早的报告源目录、辅助图册、迭代说明和历史核验记录供回溯。资料使用见 [NOTICE](NOTICE.md)。
